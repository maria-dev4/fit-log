# FitLog — Workout Library

FitLog is a dark-themed workout library built with Next.js. Users can browse workouts, view workout details, add exercises to today's plan, save workouts for later, and track completed exercises.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Toastify
- REST API

## Key Features

1. Browse a responsive workout library with workout images, muscle groups, equipment, difficulty, duration, calories, and ratings.

2. View detailed workout information including description, specifications, and step-by-step instructions.

3. Add workouts to Today's Plan with a maximum limit of five exercises.

4. Save workouts for later and view both Today's Plan and Saved workouts from My Plan.

5. Mark workouts as done, remove workouts, sort the list by duration, calories, or rating, and view live workout statistics.
